Nova Launcher

O launcher de Minecraft moderno e poderoso que você procurava

Desenvolvido em Rust com uma interface elegante e intuitiva. Suporte completo para Vanilla, Fabric, Quilt, Forge e NeoForge.

Baixar Agora Ver no GitHub

Recursos Principais

🎮

Múltiplos Loaders

Suporte completo para Vanilla, Fabric, Quilt, Forge e NeoForge. Escolha o loader que melhor se adequa ao seu estilo de jogo.

⚡

Performance Otimizada

Desenvolvido em Rust para máxima performance e eficiência. Inicialização rápida e consumo mínimo de recursos.

🔧

Controle Total

Customize a alocação de memória, escolha seu executável Java ou use o do PATH. Controle total sobre suas configurações.

📊

Barra de Progresso

Acompanhe cada etapa do processo: instalação, download e inicialização com barras de progresso detalhadas.

🌐

Versões Completas

Acesso à lista completa de versões do Minecraft: releases, snapshots, betas antigas e alphas antigas.

👤

Modo Offline

Jogue com username customizado em modo offline. Sem necessidade de conta Mojang para começar a jogar.

Como Funciona

1

Baixe o Launcher

Faça o download do Nova Launcher para sua plataforma.

2

Configure suas Preferências

Escolha o loader, versão e alocação de memória desejada.

3

Aguarde a Instalação

O launcher fará o download automático de todos os arquivos necessários.

4

Jogue!

Clique em jogar e divirta-se com o Minecraft.

Começando

Para executar o launcher a partir do código-fonte:

cargo run

Nota: O primeiro lançamento de uma versão do Minecraft pode levar um tempo enquanto os assets, bibliotecas, natives e arquivos do cliente são baixados.
